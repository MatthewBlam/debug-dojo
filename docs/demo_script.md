# Debug Dojo Demo Script

## Sprint 1 Path

1. Open the landing page at `http://localhost:3000`.
2. Navigate to `Problems`.
3. Open the seeded Two Sum problem.
4. Point out the problem statement and the Python editor.
5. Submit the starter solution to show the failing path.
6. Replace it with the hashmap solution.
7. Submit again and show the `Passed` verdict.

## Narration

Debug Dojo gives developers short Python debugging drills. Each drill
starts with realistic broken code. The user reads the problem, fixes the
function in the editor, and submits it to the local runner. In sprint 1,
the runner uses Judge0 through FastAPI and returns a pass/fail verdict for
the seeded Two Sum problem.
